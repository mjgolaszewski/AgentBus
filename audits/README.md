# Audits

Use this root for governed codebase audits, drift reviews, and operator-requested reports.

Keep reports terse: intent, scope, evidence, result, and next action. Link durable CI artifacts or hashes when referencing generated evidence.

The [dated external product review](2026-09-29-external-product-review.md) is a
hash-pinned historical record. Its release/phase language describes its original
subject; preserve those bytes. Use the [current contract model](../docs/contracts.md)
and [security policy](../SECURITY.md) for present capabilities and residuals.
